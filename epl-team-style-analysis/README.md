# EPL Team Style Analysis

## Objective

Compare Premier League teams based on playing style using public football data.

## Motivation

The Premier League has more publicly available data, making it a useful league for building a repeatable soccer analytics framework.

## Data Sources

- StatsBomb Open Data
- Football-data.co.uk
- Public team statistics

## Methodology

1. Collect team-level match or event data
2. Clean and structure the data
3. Create team-level metrics
4. Compare teams across attacking, passing, and shot creation categories
5. Visualize similarities and differences in playing style

## Planned Outputs

- Possession profiles
- Shot volume vs shot quality analysis
- Passing/progression summaries
- Team style comparison charts
