# Soccer Analytics Portfolio

Collection of soccer analytics projects using Python, SQL, public football data, and data visualization.

## Projects

### MLS Salary Efficiency Analysis

**Question:** Which MLS clubs generate the most performance relative to payroll spending?

**Tools:** Python, Pandas, Matplotlib, SQL

**Key Outputs:**
- Team payroll vs points
- Team payroll vs goal difference
- Spending efficiency rankings
- Player value relative to salary

**Status:** In Progress

---

### EPL Team Style Analysis

**Question:** How do Premier League teams differ in playing style?

**Tools:** Python, Pandas, StatsBomb Open Data, Matplotlib

**Key Outputs:**
- Possession profiles
- Shot creation metrics
- Passing/progression analysis
- Team similarity comparisons

**Status:** Planned
