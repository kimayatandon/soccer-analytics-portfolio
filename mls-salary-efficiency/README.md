# MLS Salary Efficiency Analysis

## Objective

Evaluate which MLS clubs generate the most on-field performance relative to payroll spending.

## Motivation

MLS has a unique roster structure with salary constraints, designated players, and public salary information. This project explores how efficiently clubs convert spending into performance.

## Data Sources

- MLSPA Salary Guide
- American Soccer Analysis
- MLS standings / team performance data

## Methodology

1. Collect salary data by player and club
2. Aggregate payroll spending by team
3. Collect team performance metrics
4. Join salary and performance data
5. Calculate efficiency metrics
6. Visualize spending vs performance

## Planned Outputs

- Team payroll rankings
- Payroll vs points chart
- Payroll vs goal difference chart
- Points per million dollars spent
- Player value rankings
